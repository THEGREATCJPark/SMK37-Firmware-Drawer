# 지원 근거 · 2026-11-09

모든 조합에서 이 앱을 통한 실제 USB/플래시 기록은 미검증이다. 아래 지원은 고정 실제 파일 검사, 소스 검토와 모의 프로토콜 시험을 의미한다. 실물 모델은 사용자가 확인하며 Pro / Elite / MKE를 서로 바꿔 쓰지 않는다.

기존 다섯 제품 24개 파일과 sloopDX 실험 포트 세 파일을 모두 실제 바이트로 검사한다. +VA는 별도 고정 파일과 preset 파일을 검증한다. 앱 identity는 제품 버전·실제 flash hash·장치 일련번호를 증명하지 않는다. 재연결 때 같은 물리 기기를 선택해야 한다. 재개는 identity 외에 기록·SHA·모델을 함께 확인한다.

sloopDX는 자체 실험 포트다. 소스와 세 모델 빌드는 제공하지만 실제 부팅·오디오·패널·저장·복구 검증은 남아 있다. 일반 공개판과 별도로 표시하며 최종 실험 버전 확인을 요구한다. [포트 보고서](sloopdx-port.md)를 확인한다.

## 브라우저

Windows Chrome/Edge에서 production UI, 360/390px 반응형, 파일·오프라인·모의 MIDI 포트·탭 잠금·추가 다운로드 흐름을 시험한다. 공개 Pages origin에서 개인 도우미의 두 파일을 실제로 내려받아 hash를 확인했다. 실기 USB는 수행하지 않았다.

Android는 화면 크기 에뮬레이션만 했다. HTTPS PWA 설치는 가능하지만 실제 USB 권한·전송·재열거·화면 잠금은 검증되지 않았다. +VA 도우미는 Windows용이며 Android 단독 설치 경로는 아니다. iOS 지원은 주장하지 않는다.

앱 주소: https://thegreatcjpark.github.io/SMK37-Firmware-Drawer/ . PC 로컬 주소는 http://127.0.0.1:4173/ 이며 주소별 보관함은 별개다. 서비스 워커는 설치 중 탭을 강제로 교체하거나 새로고침하지 않는다. 새 버전은 기존 탭을 모두 닫고 다시 열어 적용한다.
