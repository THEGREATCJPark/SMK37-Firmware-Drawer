# 지원 근거 · 2026-11-09

직접 어댑터는 공개 패키지의 파일 검증·프로토콜 모의시험을 뜻한다. 모든 조합의 **이 앱을 통한 실제 기기 쓰기는 미확인**이다. `SMK-37 Pro`, `SMK-37 Elite`, `MKE-P37`를 서로의 별칭으로 처리하지 않는다.

출발 family는 사용자가 실제 펌웨어를 보고 선택해야 한다. `_900`, `_470`은 여러 릴리스가 공유한다. 최종 identity는 제품 버전·실제 flash SHA·고유 장치 번호를 증명하지 않는다. 재연결 때도 같은 물리 기기를 직접 확인하고 선택해야 한다. Elite/MKE의 선행 조건과 복귀 파일은 모델별로 확인한다.

Erik37 1.2의 실제 identity `SMK-37 Pro_480102`는 재사용 모듈의 기존 3자리 loader 규칙 밖이다. 제한을 완화하지 않고 외부 경로로 유지했다. Frodhes 0.9.2 포트를 최신 0.9.9로 표시하지 않는다. ChoralRoot의 SMK 커뮤니티 0.29 계열과 FM-1 원본 0.32도 별도 행이다. 각 hash·URL·버전은 [카탈로그](../src/catalog/catalog.json), 조사 근거는 [catalog-research.md](catalog-research.md)에 있다.

PC에서는 `http://127.0.0.1:4173` 보안 컨텍스트를 쓴다. 휴대폰의 localhost는 PC 주소가 아니다. 휴대폰 시험은 사용자가 요청한 HTTPS 배포/개발 환경을 마련한 뒤 수행한다. 이 작업에서는 배포하지 않았다. 앱 업데이트 service worker는 현재 탭을 강제로 교체·새로고침하지 않는다. 외부 설치기와 아직 보관하지 않은 패키지는 인터넷이 필요하다.
