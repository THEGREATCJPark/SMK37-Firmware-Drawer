# 2026-11-12 Firmware Hub에서 얻은 개선

사용자 요청: Hub에서 유익한 기능을 가져와 기존 SMK37 개인 앱을 개선하고 실행 가능한 상태로 배포한다. 기존 한 화면 설치, 계정 없는 로컬 보관, 사용자가 직접 최종 기록 버튼을 누르는 원칙을 유지한다.

선택: 기존 React/PWA를 확장한다. Hub를 그대로 복제하거나 모든 새 파일을 자동 승인하지 않는다. 매일 GitHub Actions가 배포 정보를 조사하고, 원본/검토한 설치 버전/서명 검증/실기 여부를 분리한다. Hub 카탈로그는 출처 표시한 발견용 데이터로 활용하며 설치 허용 목록과 분리한다.

구현 순서:
1. 고정 저장소 배포 조사 + 실제 GitHub artifact attestation 검사 + 부분 실패/오래된 자료 표시. 매일 배포 스냅샷 생성.
2. 새 배포 화면, 패키지 검증 근거 카드, 모델별 복구 안내와 개인정보 없는 복구 보고서.
3. 사용자가 가져온 두 개의 전체 덤프를 실제로 비교(1MiB, SHA, trimdat). 물리 모델/보관 여부는 사용자 확인.
4. 공식 Frodhes 0.9.10 세 모델 파일 검토 후 호환성이 확인되면 설치 목록에 추가. 이전 고정 버전 유지.
5. 의미 있는 실패·무결성·UI·오프라인 테스트, 검토, GitHub Pages 배포 및 공개 웹 확인.

제약: 실제 MIDI/USB 기록·백업·복구는 수행하지 않는다. 검증되지 않은 자동 포팅/범용 바이너리 패치 기능은 표시하지 않는다. 플랫폼 전체가 Hub보다 우수하다는 보증 대신 구현된 기능과 남은 한계를 보고한다.
