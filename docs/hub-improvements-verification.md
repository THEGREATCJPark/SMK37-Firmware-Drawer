# Hub 기능을 반영한 개선 검증 · 2026-11-12

구현 범위: 제작자 정식 배포와 설치 가능 버전 비교, 하루 한 번 조사, 고정 바이너리의 실제 GitHub 출처 서명 검사, 실패 시 설치 차단, 실제 로컬 덤프 두 파일 비교, 모델별 복구 안내와 로컬 보고서, Frodhes 0.9.10 세 모델 추가.

- 단위/통합 시험: 17개 파일, 120개 통과. 실제 고정 파일의 크기·SHA·CRC·loader, wire 모의 전송, 변조/모델 불일치, 조사 실패/이전 근거 유지, 서명 digest/repository/commit 결합, 기록 직전 차단을 포함한다.
- TypeScript 검사와 배포 빌드 통과. 초기 앱 JS 308.13 kB(별도 공통 청크 187.45 kB); 백업·배포·복구·포팅 화면은 필요할 때 불러온다. lucide-react의 use client 지시문 경고는 정적 클라이언트 앱 빌드를 막지 않는다.
- Chrome/Edge UI 시험: 46개 통과. 320–1280px, 오프라인 보관, 동일 화면 다운로드, 출처 실패 차단, 백업 모델 변경/파일 교체 초기화, 복구 보고서 개인정보 제외를 확인했다.
- 수동 화면 검토: 데스크톱 배포 비교, 360px 배포 비교/복구 화면. 태블릿의 파일 입력 가로 넘침을 수정했다.
- 실제 upstream 조사: 6개 저장소 정식 배포 관측, +VA는 조사 출처 미설정으로 unknown. 발견 목록 25개는 설치 후보와 분리한다.
- 출처 서명: OberVave 3개 고정 파일 verified; Frodhes 6개와 실험 sloopDX 3개는 missing. missing은 검증 성공도 검증 실패도 아니다. OberVave의 잘못된 카탈로그 소스 커밋을 실제 빌드 커밋으로 정정했다.

제한: 기기 없이 수행한 시험이다. 실제 USB 기록·자동 전체 덤프 생성·자동 복구·임의 바이너리 패치는 수행하지 않았다. 7종/30개 모델·버전 항목은 준비된 설치 경로 수이며 실기 성공 인증 수가 아니다. 발견한 25개 프로젝트 전체의 설치 지원을 의미하지 않는다. 최종 기기 기록은 사용자가 앱에서 직접 시작한다.
