SMK37 Personal Download Helper (Windows)

1. Extract this ZIP to a folder.
2. Double-click Start-Helper.cmd and keep its window open.
3. Open https://thegreatcjpark.github.io/SMK37-Firmware-Drawer/
4. In the +VA installer, click the download button. If Chrome/Edge asks
   to connect to your local network, allow it for this page.
5. Close the helper window when finished.

The helper binds only to 127.0.0.1:19437. It downloads the original
SMK-37+VA 102 firmware and factory preset files on request and verifies
each exact size and SHA-256.
It does not save or redistribute a firmware file, access MIDI/USB,
read your personal files, or run firmware update commands.

The ZIP includes the Node.js runtime and its LICENSE. No +VA firmware
or developer installer code is included. Firmware remains the author's
work: https://baudgirl.com/work/SMK-37%2BVA
